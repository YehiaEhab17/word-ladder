# word-ladder

A programming puzzle: find the shortest number of steps to turn one word into
another, changing one letter at a time, where every intermediate step must be a
valid word.

> Work in progress.

## The puzzle

Given two words of the same length (e.g. `cat` → `dog`) and a dictionary of
valid words, find the minimum number of steps to transform one into the other,
such that each step changes exactly one letter and is itself a valid word.
